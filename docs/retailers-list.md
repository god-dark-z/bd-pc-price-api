## Notes
- Total verified here: **27 retailers** (24 original + 3 found 2026-11-08). The user's earlier Mistral list had 25 — the 25th name is not in the published top-10 lists above; check his Mistral list for the missing one before claiming 25.
- Domain correction (2026-11-08): the live Computer Source store is **computersource.com.bd** — `computersourcebd.com` does not resolve.

- Scraper order recommendation: Tier 1 first (Star Tech proof-of-concept), then Tier 2, then Tier 3. Distributors in Tier 3 often have no per-product retail price page, so they may yield fewer usable prices.
- All prices must be re-checked live — listings change daily and several of these sites show MRP vs selling price separately.
